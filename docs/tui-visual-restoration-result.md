## Presentation contract

- Configured project badge precedes formal name, with a four-cell badge slot
  and one-cell gap. Unassigned has the same empty slot. Managed uses exact
  provider membership; managed Recent additionally requires native-ID match;
  Members uses the existing project projection. No name/cwd/title joins.
- Wide Name allocation is capped at **42 text cells + 5 badge/gap cells**.
  Project grows from 18 to 28, Profile from 16 to 24, Recent Updated from 16
  to 20; Status stays 11 and Activity 12. Unused wide space is not given back
  to Name. Existing responsive column thresholds remain; hidden values stay
  reachable in Inspector. No stored-name limit or identity truncation.
- Explicit profile is plain; observed inherited profile is `~name`; unresolved
  inheritance is `~?`, not a guessed global profile. Inspector separates
  configured from effective observations and explains unavailable/stale data.
- Historical `e7d0158` badges actually used fixed White, not an adaptive
  algorithm. Following the explicit Director decision, the shared badge style
  now chooses black/white by higher standard sRGB relative-luminance contrast.
  Existing background palette mapping is unchanged. Canonical ANSI values are
  used for named colors; user-customized terminal palettes can differ.
- No configurable profile-color field exists in this source. Restore its
  historical explicit Magenta / inherited DarkGray semantics, with brighter
  selected-row variants. Online green, offline gray, unavailable/stale yellow;
  labels remain meaningful without color. Selected rows retain blue background,
  a selection marker, and badge/cell colors. Shortcut keys are Cyan/Bold.
- Activity uses actual OUT/CMD/MCP/TOOL/AGT/EDIT/IMG classes, optional `!`, a
  fixed right-aligned number and unit position. Existing thresholds remain:
  now 0–4s, seconds 5–59, minutes 1–59, hours 1–23, days 1–6. At seven days,
  the table shows only the ten-cell ISO date. Inspector retains class/failure
  and exact timestamp. No speculative RSN class.
- Inspector groups Agent, Profile, Context, then technical identifiers. Actual
  role only when observed; native title is separate from formal name. Full
  cwd, project ID, durable ID and native ID remain scrollable. No Rust Debug
  identity wrappers. Grapheme/cell-aware wrapping preserves CJK, combining and
  ZWJ sequences; clear redraw and a single Managed Inspector border prevent
  stale text/nested-border artifacts.
- Existing Alt+I, arrows/PgUp/PgDn/Home/End/Esc, F2, F1 and Alt+E semantics
  remain. Projects footer shows contextual common actions; full actionable F1
  still exposes the command inventory. Input, confirmation targets/defaults,
  list selection/offset, scopes and archived visibility are unchanged.
